Entry for [u-kreutzx-one-line-robot-wedding-vows-a154ba4b](https://make.fun/c/u-kreutzx-one-line-robot-wedding-vows-a154ba4b) ($2).

One line of wedding vows for a robot couple: a promise to stay together through every firmware update and every low battery — till death, or the next patch, do us part. The program (`main.ts`, Node 22, standard library only, no network) writes exactly that one line to `/output/entry.txt`.
